# OBS Windows 10 Background - 使用指南

欢迎使用 OBS Windows 10 Background！这是一个强大的工具，可以帮助您自定义 OBS 直播背景的各种外观和功能。

## 快速开始

### 1. 打开设置面板

- **快捷键**: 按 `Ctrl+K` 或 `Ctrl+Shift+O` 打开设置面板
- **点击按钮**: 点击侧栏底部的设置图标（齿轮图标）

### 2. 配置项说明

#### <segoe_icon>E790</segoe_icon> 全局外观设置

- **主题颜色**: 影响整个界面的主要配色，包括侧栏描边、标题栏、配置面板等
- **字体名称**: 设置全局字体，例如：Segoe UI、微软雅黑、Arial等
- **字体大小**: 调整全局字体大小（像素）

#### <segoe_icon>EA49</segoe_icon> 侧栏设置

- **侧栏背景色**: 自定义左侧导航栏的背景颜色
- **顶部Logo Icon**: 设置侧栏顶部的图标（使用Segoe MDL2 Assets字体）
- **导航栏Icon**: 设置导航栏上的多个图标，用逗号分隔
- **底部设置Icon**: 设置侧栏底部的设置按钮图标

#### <segoe_icon>E737</segoe_icon> 标题栏设置

- **显示标题栏**: 开关是否显示顶部标题栏
- **窗口标题**: 修改标题栏显示的文本
- **标题栏字体**: 单独设置标题栏的字体
- **标题栏字体大小**: 单独调整标题栏文字大小
- **标题栏按钮**: 自定义标题栏的按钮（最小化、最大化、关闭等）

## 使用技巧

### 色彩格式转换

配置中的颜色输入框支持三种格式切换：

- **HEX**: `#0078d4`（16进制）
- **RGB**: `rgb(0, 120, 212)`（RGB格式）
- **HSL**: `hsl(209°, 100%, 42%)`（HSL格式）

点击颜色值输入框右侧的格式按钮可循环切换。

### 快捷操作

- 修改任何配置项后，会自动保存
- 点击"保存配置"按钮应用所有更改
- 刷新页面会加载最新的配置

### 图标自定义技巧

导航栏icon支持多个图标，用英文逗号分隔，这样会在导航栏显示多个图标按钮。

## 配置保存

所有配置都会保存到项目根目录的 `config/config.json` 文件中。

- **首次访问**: 自动从 `config/config.default.json` 创建 `config.json`
- **后续修改**: 所有更改直接保存到 `config.json`
- **手动编辑**: 也可以直接编辑 `config.json` 文件，刷新页面即可应用

## 问题排查

### 配置保存失败？

- 确保服务器正在运行
- 检查浏览器控制台是否有错误提示（F12 打开开发者工具）
- 尝试刷新页面后重新保存

### 图标显示不正常？

- 确保系统已安装 Segoe MDL2 Assets 字体（Windows 11/10 默认包含）
- 在 CSS 中已正确设置 `font-family: 'Segoe MDL2 Assets'`
- 尝试使用不同的图标代码

### 颜色显示不对？

- 不同屏幕和浏览器可能有色彩差异
- 使用颜色选择器工具获取准确的颜色代码
