## 关于项目

这是一个为 OBS Studio 设计的直播间背景模板，试图复刻 Windows 10 时期的 Fluent Design 风格UI，提供部分自定义支持。

> **注：** 本项目的绝大部分内容由 AI 生成协助开发

## 快速开始

### 前置要求

- Node.js 14.0+ (推荐最新 LTS 版本)
- OBS Studio 27.0+ (推荐最新版本)
- 现代浏览器内核支持
  - Chrome/Edge 88+
  - （其他平台和浏览器可用性未验证）

### 安装步骤

1. **安装 Node.js**

   从 [Node.js 官网](https://nodejs.org/) 下载并安装 LTS 版本，验证安装：

   ```bash
   node --version
   npm --version
   ```

2. **克隆或下载项目**

   ```bash
   git clone https://github.com/KurotaniTakeo/OBS-Win10-Background.git
   ```

   或直接在Release处下载 ZIP 文件并解压

3. **启动服务器**
   - 点击 `启动服务器.bat` 批处理文件
   - 打开配置菜单

4. **在 OBS 中添加浏览器源**
   - 打开 OBS Studio
   - 在场景中点击 "+" 添加 "浏览器" 源
   - 本地文件选择 `obs_background.html`
   - 设置分辨率为 1920x1080
   - 勾选 "关闭源时刷新浏览器"

5. **配置透明背景**
   - 确保 CSS 中 `background-color: transparent`
   - 在 OBS 浏览器源属性中启用自定义帧速率（60fps）

6. **测试显示**
   - 按 `Ctrl+K` 打开配置面板（仅编辑时显示）
   - 调整各项参数至满意效果

## 使用说明

### 快捷键列表

| 快捷键         | 功能               | 说明             |
| -------------- | ------------------ | ---------------- |
| `Ctrl+K`       | 打开/关闭配置面板  | 主快捷键         |
| `Ctrl+Shift+O` | 打开/关闭配置面板  | 备选快捷键       |
| `Ctrl+S`       | 保存配置           | 配置持久化       |
| `Ctrl+C`       | 复制OBS浏览器源URL | 无选中文本时触发 |
| `Esc`          | 关闭配置面板       | 快速退出         |

### OBS配置建议

#### 浏览器来源设置

- **URL**: 从浏览器中复制
- **宽度、高度**: 设置为您的 OBS 画布尺寸最佳
- **帧率**: 60fps（推荐）
- **CSS**: 留空

#### 最佳实践

- 启用 "关闭源时刷新浏览器" 以节省资源
- 设置为场景级别源而非全局源
- 调整层级确保不遮挡摄像头等其他源
- 将该浏览器源锁定，防止误拖拽操作
- 使用 `Ctrl+S` 快捷键快速保存配置
- 使用 `Ctrl+C` 快速复制浏览器源URL到剪贴板

### 自定义主题

#### 更改主题色

1. 打开配置面板 (`Ctrl+K`)
2. 在 "主题颜色" 中选择新颜色
3. 所有元素会自动更新
4. 按 `Ctrl+S` 保存配置

#### 修改 CSS

编辑 `style.css` 中的颜色变量和样式

## 常见问题

**Q: 配置面板在 OBS 中显示？**

A: 配置面板默认隐藏，仅在编辑时按 `Ctrl+K` 或 `Ctrl+Shift+O` 显示

**Q: 如何更改字体？**

A:

1. 按 `Ctrl+K` 打开配置
2. 在 "字体名称" 中输入系统字体
3. 等待自动保存，或按 `Ctrl+S` 保存配置，或点击设置最下方的保存配置按钮

**Q: 如何在 OBS 中调试？**

A:

- **推荐**：在打开的浏览器中完成并保存配置后，在OBS点击刷新
- **不推荐**：在 OBS 的浏览器来源右键选择 "交互"，再打开设置页进行配置（为了您的直播效果，不推荐在直播时进行）

**Q: 如何快速复制浏览器源URL？**

A: 在不选中任何文本的情况下，按 `Ctrl+C`（无选中文本时）自动复制OBS浏览器源URL到剪贴板
